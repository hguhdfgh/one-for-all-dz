Lemo-Opuscar: 66 ستايل فيلم لـ Claude Code

إسحاق لعيب · Ishak AI4 نوفمبر 2026

Lemo-Opuscar هي مكتبة فيها 66 ستايل فيلم لـ Claude Code، من عند LemoLab. كل ستايل فيه Prompt وفيلم ديمو مصنوع كامل بالكود، بلا حتى موديل فيديو.

  • الريبو: https://github.com/lemomo-ai/lemo-opuscar
  • مضبوطة على Claude Opus، مع موديلات أخرى النتيجة تقدر تكون أقل.

المتطلبات

  • Node 20+
  • ffmpeg 7+ (ffmpeg 6.1 تاع Ubuntu 24.04 قديم، استعمل static build)
  • Python 3.11+ ولا uv
  • الفيلم الواحد ياخذ بين 30 و 60 دقيقة وتوكنز بزاف.
  • الخروج الافتراضي: 1920×1080 بـ 24 fps (تقدر تطلب 9:16).

التنصيب

الطريقة 1 — Plugin (المنصوح بها):

TERMINAL
claude plugin marketplace add lemomo-ai/lemo-opuscar
claude plugin install lemo-opuscar@lemolab

الطريقة 2 — Clone:

TERMINAL
git clone https://github.com/lemomo-ai/lemo-opuscar.git
cd lemo-opuscar
claude

مثال Prompt

PROMPT
Make a 45-second film in the watercolor style about the coffee farm my family runs. Warm female narrator.

نسخة للريلز:

PROMPT
Make a 30-second vertical 9:16 film in the [STYLE NAME] style about [YOUR PRODUCT / STORY]. Strong hook in the first second, short punchy narration, end with my brand name.

قبل، اطلب منو يوريلك الستايلات:

PROMPT
List all available Lemo-Opuscar styles with one line each, and recommend 3 that fit a short Instagram ad.
