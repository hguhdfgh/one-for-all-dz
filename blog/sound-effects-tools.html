3 أدوات ساوند إفكت لـ Claude Code

إسحاق لعيب · Ishak AI4 نوفمبر 2026

هاد الأدوات يخلّو الـ AI تاعك يحوّس، يختار، ويحطّ الساوند إفكت في الفيديو وحدو.

المتطلبات للثلاثة: Claude Code · Python 3.10 ولا أحدث · FFmpeg

1️⃣ Real SFX (من عند Clipwing)

وش تدير: تقرا التايملاين تاعك، تلقى كل لحظة تستحق صوت (woosh, pop, hit...)، ومن بعد تحطّو في الفريم بالضبط.

  • صفحة السكيل: https://clipwing.pro/skills/real-sfx
  • الكود: https://github.com/Clipwing/skills (الفولدر skills/real-sfx)

التنصيب — Mac / Linux:

TERMINAL
git clone https://github.com/Clipwing/skills.git clipwing-skills
mkdir -p ~/.claude/skills
cp -R clipwing-skills/skills/real-sfx ~/.claude/skills/

التنصيب — Windows (PowerShell):

POWERSHELL
git clone https://github.com/Clipwing/skills.git clipwing-skills
New-Item -ItemType Directory -Force "$HOME\.claude\skills" | Out-Null
Copy-Item -Recurse "clipwing-skills\skills\real-sfx" "$HOME\.claude\skills\"

من بعد سكّر Claude Code وعاود حلّو. (على Mac يطلب ffmpeg-full من Homebrew.)

2️⃣ Openverse API

وش تدير: تعطي للـ AI تاعك أكثر من 5 ملايين ساوند إفكت مجانية بجودة عالية، يحوّس عليهم ويحمّلهم وحدو. ما تحتاجش تنصيب ولا API key للبحث العادي.

  • الـ API: https://api.openverse.org/v1/
  • مثال (ساوند woosh بليسانس CC0 حر): https://api.openverse.org/v1/audio/?q=whoosh&license=cc0
  • الكود (MIT): https://github.com/WordPress/openverse

قول لـ Claude هكا:

PROMPT
Use the Openverse API (https://api.openverse.org/v1/audio/) to find CC0 sound effects for this video: a whoosh for each transition, a soft pop for each caption, and a hit on the title. Download them into a sfx/ folder and list each file with its licence and source link.

⚠️ ديما شوف الليسانس: CC0 حر 100%، وCC BY لازم تذكر صاحبو.

3️⃣ Earshot

وش تدير: كي ما تلقاش الساوند اللي تحوّس عليه، تولّدلك واحد جديد بالكود. وتقدر حتى تديرلك ساوند كيت كامل للفيديو.

  • الكود (MIT): https://github.com/Leonxlnx/earshot

التنصيب:

TERMINAL
git clone https://github.com/Leonxlnx/earshot && cd earshot
python -m venv .venv
.venv/bin/python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
.venv/bin/python -m pip install -e ".[mcp,llm,dev]"
claude mcp add earshot --scope user -- /path/to/earshot/.venv/bin/python -m earshot mcp
  • على Windows بدّل .venv/bin/python بـ .venv\Scripts\python.
  • بدّل /path/to/earshot بالمسار الحقيقي للفولدر عندك.
  • أول مرة يحمّل حوالي 1.1 GB تاع موديلات، صبّر عليه.

💡 الترتيب اللي نخدم بيه

  1. Real SFX يقرر وين لازم صوت.
  2. Openverse يجيب الصوت الحقيقي.
  3. Earshot يولّد اللي ما لقيناهش.
