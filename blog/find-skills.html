find-skills: خلّي الـ AI يلقالك السكيل المناسب وحدو

إسحاق لعيب · Ishak AI4 نوفمبر 2026

find-skills سكيل من عند Vercel. كي تسقسي الـ AI "كيفاش ندير كذا؟" ولا "كاين سكيل لـ...؟"، يحوّس في عالم الـ Agent Skills، يتأكد من الجودة، ويقترح عليك ينصّب الأحسن.

  • الكود: https://github.com/vercel-labs/skills
  • الترتيب حسب التنصيبات: https://skills.sh

التنصيب

TERMINAL
npx skills add vercel-labs/skills

أو باش تنصّبو global (لكل المشاريع) وبلا أسئلة:

TERMINAL
npx skills add vercel-labs/skills@find-skills -g -y

الكوموندات الأساسية

TERMINAL
npx skills find "video editing"          # يحوّس بالكلمات
npx skills find "seo" --owner vercel-labs # يحوّس عند صاحب واحد
npx skills add <owner/repo@skill> -g -y    # ينصّب سكيل
npx skills update                          # يحدّث كل السكيلز
npx skills init my-skill                   # يبدالك سكيل جديد تاعك

كيفاش تعرف السكيل مليح (Quality check)

  • ✅ أكثر من 1,000 تنصيب = مليح. أقل من 100 = حذر.
  • ✅ مصادر رسمية: vercel-labs، anthropics، microsoft.
  • ⚠️ ريبو فيه أقل من 100 نجمة على GitHub = راجعو قبل.
  • ⚠️ ديما شوف الكود قبل ما تنصّب.

Prompts جاهزين

PROMPT
Is there a skill that can edit my videos and add captions automatically? Find the best 3, check their quality, and tell me which one to install.
PROMPT
Find me a skill for writing Instagram captions in my own voice. Show name, installs, source and the install command.
PROMPT
I want to make better landing pages. Search skills.sh and recommend the most installed skill for that, then install it globally.
