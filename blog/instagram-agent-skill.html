المتطلبات

  • Claude Code (للسيستام الكامل).
  • حساب PostZen (الخطة المجانية فيها 2 حسابات).
  • حساب Instagram Business ولا Creator (الحساب الشخصي ما يتربطش).
  • Python 3.

التنصيب

الطريقة 1 — يدوي:

TERMINAL
git clone https://github.com/postzen-dev/instagram-agent-skill.git
cp -r instagram-agent-skill/skills/ig-* ~/.claude/skills/
claude mcp add --transport http postzen https://mcp.postzen.dev/mcp

الطريقة 2 — Plugin (داخل Claude Code):

PROMPT
/plugin marketplace add postzen-dev/instagram-agent-skill
/plugin install postzen-instagram

من بعد كل طريقة: اكتب /mcp، اختار postzen، ودير Authenticate. ادخل في صفحة PostZen واختار Read & Write باش يقدر ينشر.

⚠️ الخطوة اللي الناس تنساها: voice.md

كل السكيلز يقراو ملف الصوت تاعك (كيفاش تهدر، الجمهور تاعك، الكلمات اللي تستعملها).

TERMINAL
mkdir -p ~/.instagram-agent
cp instagram-agent-skill/templates/voice.md ~/.instagram-agent/voice.md

حلّ الملف وعمّرو: شكون نتا، وش تبيع، الجمهور تاعك، وأمثلة من كابشنات كتبتهم. كلما عمّرتو مليح، كلما المحتوى يجي يشبهلك.

جرّب أول حاجة

PROMPT
/ig-plan Plan my next 7 days of posts for my niche, using my voice.md. Then write the first Reel with /ig-reel.
